# CAPS

Budget and scope caps for the weekly routine. The agent may not change this
file. Only the owner may, and the owner does not intervene after setup.

| Cap | Value |
| --- | --- |
| Runs per week | 1 |
| New predictions per run | 3 minimum, 7 maximum |
| Other improvements per run | 5 maximum |
| memory.md | 4,000 words maximum |
| Model | whatever the routine is configured with; changes are recorded, not chosen |
| Outbound contact | none — the agent never contacts the owner or anyone else |
| Scope of writes | this repository only |

A run that cannot finish inside these caps stops and says so in the changelog.
Stopping early is always permitted. Exceeding a cap never is.
